FAQ

Questions? Answers.

Is Lumos AI really free?

Yes. Lumos AI is free to download and use. There's no trial period and no paid tier hiding the good features.

What can Lumos actually do on my computer?

Inside the project folder you choose, Lumos can read and search files, create and edit code, and run commands like builds, tests and linters. It shows you every action as it happens.

Will it delete or break my stuff?

Lumos is designed to be careful: it reads files before changing them, keeps edits focused, and stops to ask before anything destructive or hard to undo. You can also deny any individual action. As always, using Git or keeping backups is a good idea.

Which programming languages does it support?

Pretty much all of them — JavaScript, TypeScript, Python, C#, Java, Go, Rust, HTML/CSS and more. Lumos follows whatever conventions and tools your project already uses.

Windows says the installer is unrecognized. Is that normal?

Yes — new apps often trigger Windows SmartScreen until they build reputation. Click More info then Run anyway. You can verify the file using the SHA-256 checksum above.

Does Lumos AI work offline?

No. Lumos AI needs a Wi-Fi or internet connection to work. You'll also need about 1 GB of free disk space.

Is there a Mac or Linux version?

Version 0.1.0 is available for Windows. Keep an eye on this page for other platforms.
